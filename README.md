# basis-craft

Работа с моделями Базис-Мебельщика (`.b3d`) без Базиса: спецификация деталей, раскрой листов, карты раскроя и проект для БАЗИС-Раскроя.

## Сборка

```
cargo build --release
```

Программа появится в `target/release/basis-craft`.

## Окно

```
target/release/basis-craft-gui [модель.bcraft | модель.b3d]
```

- **Слева** — проект: материалы, кромка, корпуса. У корпуса задаются габариты, цоколь, двери, материалы, перегородки и полки. Каждое изменение сразу пересобирает детали; недопустимое изменение не применяется, причина видна внизу окна.
- **Вкладки:**
  - «Вид спереди» (двери можно скрыть);
  - «Детали» — таблица с пильными размерами и кромкой;
  - «Раскрой» — листы по материалам.
- **Меню «Экспорт»:** карты раскроя (HTML), проект для Раскроя (XML), спецификация и смета (CSV).
- **Модели Базиса** открываются только для просмотра: детали, раскрой, экспорт.

## Команды

| Команда | Что делает |
|---|---|
| `basis-craft cut модель.b3d [--sheet 2750x1830] [--kerf 4] [--trim 10]` | Раскраивает детали по листам. Результат — `модель.html`: карты раскроя в стиле БАЗИС-Раскроя и листы «Панели в производство». Откройте в браузере и распечатайте (или «Сохранить как PDF»). |
| `basis-craft raskroy модель.b3d [--sheet 2800x2070]` | Пишет `модель.xml` — проект для БАЗИС-Раскроя в том же формате, в каком его передаёт Мебельщик. |
| `basis-craft spec модель.b3d -o spec.csv` | Спецификация деталей для Excel. |
| `basis-craft smeta модель.b3d [--coef 1.2]` | Расход материалов: плиты (м²) и кромка (м), с округлением как в смете Базиса. |
| `basis-craft dump модель.b3d 3` | Дерево модели, нужно для отладки. |

Вместо `модель.b3d` во всех командах можно указать свой проект `.bcraft`. Тогда формат листа и коэффициент берутся из материалов проекта.

### Свой проект

```
basis-craft design шкаф.bcraft material.add '{"name":"ЛДСП Белый 16","thickness":16,"sheet":[2750,1830]}'
basis-craft design шкаф.bcraft edge.add '{"name":"ПВХ 0,4","thickness":0.4,"width":19}'
basis-craft design шкаф.bcraft cabinet.add '{"width":1200,"height":2200,"depth":600,"material":"ЛДСП Белый 16","edge":"ПВХ 0,4","plinth":80,"doors":2}'
basis-craft design шкаф.bcraft shelf.add '{"cabinet":1,"height":700}'
basis-craft cut шкаф.bcraft
```

`basis-craft design --help` — список команд. Изменение, после которого изделие не собирается (например, полка выше корпуса), отклоняется, и файл не меняется.

Параметры:
- `--sheet` — формат листа в мм;
- `--kerf` — ширина пропила;
- `--trim` — обрезка края листа с каждой стороны.

## Устройство

- `crates/basis` — вся логика:
  - `b3d.rs` — чтение файла;
  - `contour.rs` — контуры;
  - `panel.rs` — детали и кромка;
  - `nest.rs` — раскрой;
  - `report.rs` — карты и таблицы;
  - `raskroy.rs` — XML для Раскроя;
  - `design.rs` — свой проект: корпуса и команды;
  - `job.rs` — общий сценарий «открыть → раскроить → документы» для CLI и окна.
- `apps/cli` — командная строка.
- `apps/gui` — окно (egui 0.36, как у cadcraft и craft-libs).
- `docs/formats/b3d.md` — описание формата `.b3d`.
- `docs/backlog.md` — что запланировано.
- `example/` — образцы моделей.
- `reference/` — эталоны из Базиса:
  - проекты Раскроя, карты, руководство;
  - `pairs/` — модель вместе с документом, который Базис по ней выдал (по паре `sanuzly` идёт автотест сметы);
  - `reports/` — выгрузки спецификаций и смет в Excel, задание `.cutwork` (оно зашифровано);
  - `cnc/` — программы для станков с ЧПУ;
  - `scripts/` — скрипты BAZIS-Script и заметки по ним.
- `example/telegram/` — ещё около 200 моделей и фрагментов фурнитуры для проверки чтения.

Проверка: `cargo test --release`.
